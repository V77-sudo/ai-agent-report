AGENT USAGE

各有侧重，
让每个 Agent 用在合适的地方。

以 WorkBuddy 为主、Trae 为辅。以下是常见的协作场景，记录实际分工与工作方式。

🧠
01 · WORKBUDDY · PRIMARY

日常问题与任务拆解

把模糊目标、零散需求交给 WorkBuddy，协助梳理重点、列出步骤，并把复杂任务拆成可执行的小项。

我的做法：先说明目标和限制，再逐步确认计划与结果。
适合：任务规划、问题梳理、快速获取思路。
✍️
02 · WORKBUDDY · PRIMARY

文字整理与内容创作

用 WorkBuddy 整理资料、起草邮件或总结、润色表达，也可以根据受众调整结构和语气。

我的做法：提供背景与受众，把初稿当作起点，最后由我核对事实和语气。
适合：文档草稿、摘要提炼、表达优化。
🗂️
03 · WORKBUDDY · PRIMARY

资料归纳与信息提炼

面对较长材料或多个信息来源时，请 WorkBuddy 提炼重点、归类信息，并整理成清单或摘要。

我的做法：明确需要提取的信息，再检查摘要是否遗漏上下文。
适合：会议要点、资料归纳、待办清单。
💻
04 · TRAE · SECONDARY

代码编写与项目开发

在开发任务中使用 Trae 辅助理解项目、编写或调整代码、定位问题，并推进从想法到可运行实现的过程。

我的做法：提供项目上下文与目标，分小步修改，检查变更并实际运行验证。
适合：代码实现、项目迭代、开发流程辅助。
🔎
05 · TRAE · SECONDARY

理解代码与排查问题

遇到陌生模块或运行问题时，请 Trae 帮忙解释代码关系、梳理可能原因，再针对具体问题逐步验证。

我的做法：提供相关报错和代码上下文，先理解方案，再验证修复效果。
适合：代码阅读、调试分析、变更检查。
🔁
06 · WORKBUDDY + TRAE

从想法到交付的协作

需要兼顾需求表达与技术实现时，先用 WorkBuddy 梳理目标和内容，再用 Trae 协助落地开发，最后由我统一检查。

我的做法：根据任务切换工具，必要时分阶段协作，不让工具选择变成额外负担。
适合：跨越规划、内容与代码的综合任务。
A SIMPLE LOOP

我的 Agent 协作小循环

无论使用 WorkBuddy 还是 Trae，都从清晰的目标开始；Agent 加速执行，我负责判断方向、核验结果。

🎯明确目标

说明要完成什么、已有信息和限制条件。

🧩选择 Agent

日常整理优先 WorkBuddy，编程任务使用 Trae。

⚙️分步协作

给出具体反馈，逐轮调整内容或实现。

✅检查交付

核对事实、代码与实际结果，再决定是否采用。

REFLECTION & NEXT
